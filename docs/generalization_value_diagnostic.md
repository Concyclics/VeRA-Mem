# 数据增强后的寻址与写入诊断

本次开发集诊断发现两处具体问题：未见问句的实体寻址仍接近随机；普通多模板增强后的 value 向量大量表示模板差异，同一事实甚至会因观测措辞改变而产生方向相反的 value。这为下一步跨表达一致性训练提供了依据，尚不能说明该干预一定能恢复生成泛化。

证据保存在 [聚合诊断 JSON](results/generalization/value_diagnostic.json)，重现脚本为 [diagnose_generalization_values.py](../scripts/diagnose_generalization_values.py)。本次只比较 `canonical4096` 与 `augment4096` 的最佳检查点；两者选中第 1536 步。所有统计、原型和诊断头只使用训练集与开发集。未使用确认集的特征、答案或预测进行诊断或选择下一步方案。

## 1. 问句变化后，寻址尚未迁移

开发集有 64 个训练中未见的实体。每个检索库包含这 64 个实体的对应观测。下表是冻结 Q/K 编码器在实际层输入特征上的 Recall@1，不是语言模型生成正确率。随机 top-1 水平为 1/64，即 1.56%。

| 开发条件 | 单模板训练 | 普通增强训练 |
|---|---:|---:|
| 原问句 + 原观测格式 | 64/64 | 55/64 |
| 请求卡片问句 + 原观测格式 | 3/64 | 2/64 |
| 前置输出约束问句 + 原观测格式 | 2/64 | 2/64 |
| 请求卡片问句 + 记录卡片观测 | 1/64 | 2/64 |
| 前置输出约束问句 + 新措辞观测 | 1/64 | 1/64 |

因此，本次普通增强没有把实体匹配规则稳定迁移到开发问句。增加已见问句种类与学到可迁移的寻址表示之间仍有距离。

## 2. Writer 在训练表达间产生了方向翻转

我们把同一训练事实的不同观测表达分别编码为 value，对完整训练数据做平衡的“模板 × 答案”方差分解。模板主效应是各模板 value 均值相对全局均值的偏移；答案主效应是各答案均值的偏移。剩余项包含实体差异及答案与模板的交互，不能全部解释为噪声。

| Writer 训练条件 | 模板主效应 | 答案主效应 | 剩余项 |
|---|---:|---:|---:|
| 单模板 | 0%（定义上为零） | 92.39% | 7.61% |
| 四种观测表达增强 | 84.75% | 8.19% | 7.07% |

增强模型中，同一事实的 `train_support_00` 与 `train_support_02` value 平均余弦相似度为 **−0.875**。前者使用 “The assigned memory word ...” 的叙述，后者使用 “Store this association ...”。原表达与另外两种训练表达的对应余弦分别为 **+0.932、+0.940**。模板平均方向差异占据了 value 的主要方差，而不只是小幅数值扰动。

混合所有训练表达后的 value 有效秩为 2.25；单模板模型为 8.67。这个有效秩使用至多 1024 个均匀采样行的中心化谱估计。上述方差分解则使用全部训练行，因此它是模板支配更直接的证据。有效秩低本身不等于记忆失效。

开发集新观测格式的 64 个 value 都互不完全相同，但平均两两余弦为 0.918–0.970。增强模型第二种新观测措辞与对应事实原格式 value 的平均余弦为 −0.319。这说明仅检查“value 是否唯一”不足以验证跨表达兼容性。

## 3. 线性诊断头只能说明当前读出规则的迁移能力

另训练独立的 16 类线性头判断答案词。它不属于 VeRA 模型，不写入 VDB，也不参与任何实际推理。所有头使用训练事实标签、固定 256 步 × 128 样本、Adam 0.001；不按开发表现选步数。归一化中心仅从各自训练特征计算。随机答案分类水平为 4/64，即 6.25%。

| 诊断头输入与训练表达 | 原观测格式 | 新记录卡片 | 新观测措辞 |
|---|---:|---:|---:|
| 单模板模型的 writer 输出 | 64/64 | 4/64 | 7/64 |
| 增强模型的 writer 输出 | 62/64 | 11/64 | 14/64 |
| 冻结 backbone 层输入，单模板训练头 | 64/64 | 16/64 | 5/64 |
| 冻结 backbone 层输入，四模板训练头 | 64/64 | 6/64 | 9/64 |

原格式下的 writer 输出仍携带可被另一个线性头解码的答案信息。新观测格式下，这些训练出来的读出规则迁移较差。**低分不能证明隐藏表示中不存在答案信息**：诊断头的训练方式、线性表达能力、归一化方式和有限预算都可能影响结果。单模板与多模板诊断头的训练特征池大小也不同，虽然优化步数和样本暴露数相同。尤其不能把线性头的 64/64 当作 VeRA 生成模型的 64/64。

训练答案原型的余弦分类也给出一致方向：增强 writer 在原格式上的原型分类为 53/64，在两个新格式上分别为 7/64 和 11/64。先减去训练 value 均值后分别为 55/64、9/64、11/64；移除单一公共均值不能恢复跨表达读出。

## 4. 对后续实验的具体启示

应同时约束同一事实不同表达的 Q、K 和 value，使这些表达进入兼容的地址与 VeRA 参数空间；地址损失仍需其他实体作为负例，避免仅通过收缩表示满足一致性。接下来应检验一致性约束是否减少模板主效应、恢复未见问句寻址，并最终改善真实稀疏检索下的生成表现。几何统计或额外诊断头提升都不足以单独确认成功。

这些结论来自 64 个开发实体、16 个共享答案词和一个训练种子，适用于定位当前实现的问题。若基于这里的诊断更改实现，应保留确认集的独立角色；不能将开发集改进或已用于训练的历史 paraphrase 重新称为未见模板泛化。
