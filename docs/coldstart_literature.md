# Cold start, foundation dictionaries, and sparse optimization: literature map

Checked on 2026-10-06. The discussion below is based on the original papers and author repositories. Detailed section references, training budgets, and derivations are recorded in the [evidence file](results/coldstart/literature.json). The [fixed protocol](coldstart_protocol.md) defines what this round actually executed; early recommendations in the evidence file are not completed experiments.

Foundation slots in PKM and Memory Layers are independently trainable parameters. Our design also includes episodic records generated by a shared writer's forward pass. One writer update affects the values generated for all future records. Therefore, a cached vector not being selected is not equivalent to an independent embedding parameter never being updated. This round separates the shared foundation dictionary from individually replaceable new facts to avoid conflating these two kinds of memory.

## Testable changes adopted in this round

The data controls first compare no gradient warm-up, warm-up on compact observations with the same answers, and warm-up on natural Wikipedia paragraphs. Foundation-dictionary conditions then compare fixed values, ordinary sparse training, dense-to-sparse training, and straight-through training. In `wiki_joint`, the dictionary additionally participates in Wikipedia warm-up. That changes both warm-up routing and foundation-memory use, so it is not a single-factor control.

The straight-through estimator is applied to the **mixed output**. With `y_s = p_sparse @ V` and `y_d = p_dense @ V`, we use `y_d + stop_gradient(y_s - y_d)`: the forward output is sparse, while the backward pass uses the dense Jacobian. Merely defining `p_ST = p_dense + stop_gradient(p_sparse - p_dense)` and then multiplying by `V` still gives value gradients determined by the sparse forward weights; it does not justify claiming that every value receives a gradient. This output-level method is a biased surrogate-gradient diagnostic proposed for this experiment, **not a recipe jointly validated by the papers above**. Dense backward computation has a real cost, and tiny nonzero gradients do not establish effective learning.

Foundation-prototype compression uses only trained checkpoints, never confirmation-set content. The same prespecified checkpoint is evaluated with full 1024, off, random 256, and cluster 256. Clustering retains arithmetic means without additional RMS rescaling or log-count corrections. These controls simultaneously change capacity, top-k competition, and weight quality. A higher coverage percentage caused by a smaller denominator must not be called a training or inference improvement. New-fact records remain independent and are not averaged with contradictory facts.

## Limitations that conclusions must retain

This round is not Wikipedia-scale pretraining: warm-up is only 1024 steps × 8 targets. Actual unique targets, bank exposures, and token counts must be reported; 32,768 candidate records must not be described as all having received target supervision. Training uses only the canonical view, with P=A, so the AP term provides no independent paraphrase augmentation. All main comparisons share one fresh initialization seed. The Qwen backbone is frozen, with one set of fixed rank-64 random projections at layer 20. Adding dictionary slots does not expand the output subspace of those readout projections.

Inspect contextual teacher A/B qualification, full paired EM/NLL on real new facts, retrieval recall, top-1/top-k slot coverage, and gradient coverage together. If coverage improves while real HC readout does not, the evidence supports only a change in optimization paths or slot utilization, not a solution to generalization. Failure of every control in this round also cannot rule out larger budgets, stronger writers, multilayer memory, or higher-capacity readout. The proposed combination and efficiency advantages still require evidence; one-shot writing, sparse memory, and generating parameters from text should not themselves be claimed as novel.
