# 反事实上下文蒸馏实验协议

本轮检验：在同一问题下，只改写入记忆中的一个事实，学生能否正确改变答案；只改写事实的表达时，能否保持答案。前一轮存在固定输出 apple/silver 的现象，因此主要验收指标是两边都答对的 paired-switch EM，而不是输出发生变化、hidden 更相似或单边准确率。

## 固定数据和干预

训练复用4096个历史训练实体和8种问题、4种观测表达。每个实体有两个不同值 A/B，替代值在答案 token 长度组内生成随机 derangement，保持每个值在两边的边际频率相等；不同组不共享一个固定 A→B 映射。真实 tokenizer 必须验证两个值的首 token 不同，A/B teacher prompt 总长度也必须相同。

每个训练 batch 为8个目标，各自拥有72条记录的独立银行。每个目标的 B 银行只替换它自己的那一条观测，其余记录不变；P 银行只将同一条 A 观测换为另一训练表达。正常 writer 同时产生 key/value，因此这是观测更新的总干预，不宣称纯 value 因果效应。实际张量银行按 batch row 独立检索，不能将八个目标同时替换后称为八个单条干预。

训练负例包含与目标 A/B 答案相同但实体不同的记录；这些记录仍是地址分类的负例。问题渲染只访问实体，答案、世界标识、正确记录 ID 不进入 student prompt 或检索 API。A/B/P 在同一参数快照下完成前向，再共同反向传播并进行一次 optimizer 更新。

新确认集固定64个实体，seed27042，与历史 train/dev/test/control 及早期实体排除集不重合。JSON 与 Markdown 表格是本轮保留的两种结构族；每个 A 标签和每个 B 标签在两种 query×两种 support 的四个组合中各出现一次，避免按实体索引分配风格造成答案偏置。旧开发集不用于本轮选模。确认缓存与训练缓存分开；正式训练只加载 train.pt。

Smoke 使用32个训练实体和其中4个实体的训练表达作小评测，不使用新确认样本选择实现或配方。正式缓存可预先计算冻结特征，但所有正式训练完成后才测量新确认集的 teacher/student 行为。

## 共享模型与预热

基座固定 Qwen3-4B-Instruct-2507，revision `cdbee75f17c01a7cc42f958dc650907174af0554`。保留第20层 mlp.down_proj、rank/key64、top-k4、temperature0.05、冻结随机 A/B。初始化使用历史 anchored_all_view checkpoint，不按本轮评测挑选。

先执行256次 batch-8 的共同预热；随后四个方法从相同 module 与 Adam optimizer 状态出发，各执行512次 batch-8 续训。训练事实/负例/视图随机序列一致，seed42。预热2048次目标对曝光，续训4096次目标对曝光；各对还包含 A/B/P 三个监督分支。固定最后一步，不依据确认结果延长训练、挑 checkpoint 或修改损失。

Wv 学习率1e-4，共享 b 为0.005，Wq/Wk为1e-5，三个参数组分别裁剪梯度范数至1。每4步按相同目标做原格式 A 世界答案回放，回放权重0.25。该方案的训练量与数据均不同于前一轮，历史分数只能作背景，不能识别反事实数据本身的因果收益。

## 四个训练条件

| 方法 | 增量 |
| --- | --- |
| base | 成对数据的绝对监督及公共寻址与改写一致性 |
| behavior | base 加0.1反事实行为差分损失 |
| hidden | behavior 加0.1反事实 hidden 差分损失 |
| mixed | hidden 在续训中每4步将一次 FKL 的正确前缀替换为学生公共轨迹 |

公共目标为 A/B/P 三边的完整词表 forward KL 平均，加0.5首 token 正确标签 CE；另加0.2实际预测位置地址 CE、0.2全训练风格地址 CE，以及0.05 A/P 首位置输出 JS。所有组均使用成对值与等价改写数据。因此四组识别的是损失和轨迹配方的增量，不能单独区分“有无成对数据”。预热使用 base。

Teacher 是禁用 VeRA 的冻结原模型，获得本分支观测原文；student 只输入问题并读取向量库。每个 teacher/student 分支使用完全相同的 continuation token IDs。没有通过 decode/re-tokenize 重建前缀，也没有在采样截断时补充人工 EOS。

行为差分只在**答案出现前的首个预测位置**比较。定义每边两个候选的 log-probability margin，令效果量为 margin_A−margin_B。用 SmoothL1 匹配教师效果；教师目标裁剪至±10，学生不裁剪，辅助权重0.1。只有教师分别偏好正确 A/B 候选且效果量非微小时该辅助项有效，记录门控覆盖率与裁剪比例；首 token 全词表 CE 始终有效。候选偏好门控不等于教师对完整词表和完整答案都正确，需单独验收。

Hidden 取最终 RMSNorm 后状态。先各自 L2 归一化，再计算 Δh=h_A−h_B，损失为 `||Δh_student−stopgrad(Δh_teacher)||² / max(||Δh_teacher||², 1e-6)`。教师差分范数小于1e-3的 pair 不进入该项均值，并报告覆盖率；有效 pair 上零学生差分的损失为1。它同时约束幅度和方向，不把任意微小同方向变化视为成功。教师差分也不能直接称为纯语义方向。

Mixed 的128次学生轨迹更新中，每个目标随机选择 A 或 B 银行采样一条序列（温度1、最多4 token），将这条公共序列用于 A/B/P 的 FKL。它是两种学生 policy 的混合，不是每边都仅使用自身轨迹。首 token 标签 CE、首位置反事实差分和公共地址目标保留；替换前缀而不增加更新数。因为长度、结束符、地址目标所见状态和首位置权重也可能变化，结果衡量整体学生前缀配方。实际 token、采样次数和耗时单独计量，不声称等 FLOPs。

## 冻结后的评估

同一批64个新实体评估四象限：原观测/原问句、原观测/新问句、新观测/原问句、新观测/新问句。每个目标独立构建 A 银行、替换自己的记录得到 B、等价改写自己的记录得到 P。保存基库与可精确重建的更新补丁，核查其他记录及共享模型未改变。

每个条件运行 real 的 A/B/P，shuffled 的 A/B，强制正确 value 的 oracle A/B，以及一次 empty 生成分别对 A/B 评分。相同 shuffle 置换应用于两个银行，并保持 key 不变。Oracle 改变了 top-k 混合分布，仅作诊断。两个对角象限另外测量另一无关实体在更新前后的表现；每个目标从自己的 A 银行副本出发，防止多次更新累积混淆。

主指标 `PairedSwitchEM = mean(EM_A AND EM_B)`。另报告 A/B 单边 EM、输出变化率、错→错变化率、同事实改写 A/P joint EM 与预测一致性、正确记录 R@1/R@4 和 decode 驻留，以及无关问题保持率。有上下文 teacher 在初始评估中验收 A/B/P；全样本为主表，教师两边都正确的条件子集同时报告覆盖率，不只展示过滤后的结果。

初始 anchored 模型与四个最终模型在相同确认样本上评估。每个方法只有一个训练 seed；配对 bootstrap 以实体为单位，跨四象限时将同一实体的全部条件一起抽样。该区间不覆盖训练 seed 或新结构族的不确定性。

本轮是有限词表的机制实验。若 paired-switch 仍接近零，保留完整负结果，不通过同一确认集反复试损失挑选高分；后续应另设新验证，研究写入特征、多层容量和真实多 token 事实。
